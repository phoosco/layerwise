The project

Useful information, not made-up ratings.

Layerwise is being built around garment properties and real-world use. Manufacturer data, community knowledge and personal experience should be distinguishable rather than blended into one supposedly precise temperature rating.

How catalogue status works

CURATED Checked against manufacturer specifications or another identified reliable source.

UNVERIFIED Submitted by a user; visible as a contribution, but not treated as confirmed product data.

LOCAL ONLY Saved in this browser for now. Shared contributions will require a connected database.

What comes next

First: build a trustworthy garment data structure. Then: connect shared storage, add review tools, and improve the estimator using garment properties and user feedback.

Important: This is a catalogue prototype, not a safety tool. It does not yet predict safe operating temperatures or replace weather judgement.
Reference library

Clothing catalogue

Browse the starter records, filter by category, and add garments to your wardrobe. The initial catalogue deliberately avoids pretending that unverified specifications are facts.

Specifications are shown only when there is a source to support them. A blank field means “not recorded”, not zero performance.
Community contribution

Submit a garment

Add an item missing from the catalogue. Your submission will be labelled unverified until its specifications and source can be checked.

Please don't guess technical values. Leave unknown fields blank. Personal experience is useful, but keep it separate from manufacturer specifications.

What happens to it?

  1. Your entry is saved in this browser.
  2. It appears in the catalogue as unverified.
  3. It can be checked against the linked source.
  4. Only after review should it become a curated record.

This prototype does not yet send submissions to a central review queue. Other visitors will not see your local submission.
